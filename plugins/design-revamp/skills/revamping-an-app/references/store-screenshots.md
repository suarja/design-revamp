# Revamping store screenshots

Drawn from 43 store strips in the shared design bank and from one real pack. Ids in parentheses resolve in the shared library described by design-bank, on the owner's Mac only: never copy, commit or publish those images.

A strip is not a tour of the features. It is one argument, read in seconds by a stranger scrolling past. Most people see only the first three panels, in a search result.

## Steps

1. **Read the listing as a stranger.** Draw the current strip under the real name and subtitle at search-result size. Note what a person understands from those three panels alone. Check that the positioning in the screenshots, the name, the subtitle, the description, the keywords and the header and search visuals still say the same thing: they age together.
2. **Write the argument before any layout.** One sentence per panel, one idea per panel, read in order. Panel 1 carries the promise or the pain. Then the gesture, the proof, the depth, the reason to come back. Titles name the fear or the desire, never the function: a friendship that fades, not reminders (e24035ae). Answer the exact worry: « 3 weeks and no change? » (8445fa6a). A name can become a verb on panel 1 (9c00a635). Six words at most. Propose three titles per panel, recommend one, let the owner strike.
3. **Choose the thread that holds the strip.** Several panels read as one thing only if something runs through them. Options seen: a decor running under every panel with a different character each time (d7700f5b), one drawn line (14195e38), one colour that darkens or stays put (0ceb7418, f3390202), one character fixed in the same corner while colours segment the functions (953eb750), one object repeated (6d0c910d), one gesture repeated with only the score changing (5a76dade), a character straddling two panels so one scrolls to see the rest (5822fc05). Prefer a thread taken from the product's own mechanic: it explains the product while it holds the strip.
4. **Prove on every panel.** Show the gesture and its gain, not a phone being presented: a hand that breaks the frame stops the scroll (fe52cb7a). Pull one element out of the capture and enlarge it; a phone at full size has unreadable text. Let an object straddle the capture to join promise and proof (6135b7b6). Show real use rather than a generic mock (905cc069). A long text result reads as a document held in the hand (b2e761ef).
5. **Make the words carry.** One highlighted word per panel can act as the logo of the promise (451ee89c), or the title can alternate lines for rhythm (582ddee5). A number is exact when it is the proof (3347da3a). A title may be cut by the frame when speed is the point (76ecb699). Check legibility at search size, not at full size.
6. **Choose the opening.** Panel 1 can show the gain in two numbers and no interface (7af9d073), people using the product (f48ab6bd), or the character alone (19bfbe89 closes on it). Claim only what the product does at release.
7. **Draw before exporting.** One canvas: the old strip, then one or two proposals with their thread, then the first three panels inside a mock search result. One verdict per strip.
8. **Produce from the shipped build.** Screenshots come last, from real captures of the shipped design, on the required simulator size, with an account the owner owns and signs into himself. Never a screen that has not shipped. Compose from the source captures so the pack can be regenerated when the interface changes.
9. **Check the rest.** Verify required sizes in the store's documentation before export (the last pack used 1290×2796 RGB, no alpha). Write the copy of each language in its native idiom, never translated. Look at the rights on every third-party image or face that appears in a capture before publishing. Check that no board annotation or sample mark leaked into the image.

## Traps

| Symptom | Cause | Fix |
| --- | --- | --- |
| Six panels that read as six separate ads | no thread | one element running through, taken from a mechanic |
| Every title starts with the app's name or "I" | written from the product's side | start from the person's state |
| Unreadable screens inside the phones | whole screen at phone scale | enlarge one element, cut the rest |
| Strip promises the old product | screenshots regenerated last, positioning changed first | update the argument at the same time as the name |
| Same title for every locale | translated tagline | native idiom per locale |
